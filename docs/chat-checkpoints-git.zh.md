# 聊天内改动审阅与 Git 管理

聊天是入口。每轮结束出现改动卡片；点击文件或“查看改动”，在右侧打开“改动 / 检查点 / Git”。收起面板保留聊天草稿、消息和滚动位置。历史会话不补造检查点，通用聊天和只读后台会话不提供文件恢复操作。

## 自动检查点

检查点独立于 Git，普通文件夹可以使用。Gateway 按实际目录创建存储，内容以 SHA-256 对象去重，清单、文件工具编辑日志和恢复日志通过临时文件原子发布。文件工具写入前保存原内容、写入后保存结果；每轮前后扫描目录补充 Shell 等命令产生的新增、修改和删除。

检查点保存内容、文件是否存在、权限及对话上下文。二进制文件可恢复，不展示文本 diff。备份默认单文件上限 10 MB、每次目录扫描预算 256 MB，排除 `.git`、`.pilotdeck`、依赖、缓存和构建目录。文件工具直接修改排除目录里的普通文件时仍记录该次修改，Git 内部文件除外。目录外文件与命令的外部副作用不在本目录检查点范围内。

每个会话保留最近 100 轮与 100 次已完成恢复。未完成的恢复、有效预览及它们引用的备份不清理；随后回收不再引用的内容对象。备份留在本机 PilotDeck 数据目录，不创建用户 Git 提交。

进程中断后通过持久化文件工具日志恢复未完成轮次的记录。没有可靠修改后版本的变化允许查看，但不自动覆盖文件，避免误撤回进程退出后的手动编辑。

## 恢复行为

预览逐文件比较修改前、修改后和当前版本：当前等于修改后时允许恢复，等于目标时无需处理，其余情况保留为冲突。确认时再次校验，预览过期或内容变化时要求重新审阅。第一版按整个文件保留冲突，不自动合并冲突片段。

恢复前保存当前状态，并写入操作日志。每个文件写入前记录待处理路径，写入后记录已完成路径；中断后可以从日志恢复，即使进程退出发生在文件写入与完成标记之间。“撤销这次恢复”也生成预览，并保护恢复后再次发生的编辑。

支持仅恢复文件、文件与对话一起回退、仅回退对话。对话回退向原始 transcript 追加恢复边界：UI 投影与模型重放使用恢复后的分支，原始记录仍保留。恢复会清除缓存会话与文件缓存，并提示模型重新读取相关文件。恢复后产生新对话轮次，再撤销原恢复时默认只处理文件，保留后续对话。

轮次 diff 固定展示历史版本；会话汇总计算当前分支的净修改，并计入恢复与撤销恢复操作。

## Git

Git 页签展示整个真实仓库，区分未暂存与已暂存；包含手动编辑和其他会话改动。支持初始化普通文件夹、查看分支、切换已有本地分支、暂存/取消暂存、首次提交、提交、配置 origin、Fetch 和 Push。文件名通过 NUL 分隔状态解析和 literal pathspec 传递，保留空格、换行与重命名信息。

Commit 明确提交暂存区全部文件，核对用户审阅时的 index tree，保留未暂存内容。Push 按已有跟踪关系推送当前分支；首次推送优先使用 origin，未配置 origin 时使用已有远程，并设置跟踪分支。Git 身份和凭据沿用系统已有配置。

Agent 轮次、恢复与 Git 变更在 Gateway 使用目录租约协调；父子目录与同一仓库的操作互斥，独立目录仍可并行。外部编辑器不受该租约控制，因此恢复与提交还要做状态校验。

## 验证

后端测试覆盖普通文件夹、文件工具与目录比较、二进制、权限、冲突、过期预览、符号链接、进程中断、撤销恢复、对象清理、模型上下文重启、历史分支、Git 暂存区与首次推送。

前端测试覆盖聊天内入口、侧栏收起与草稿保留、冲突选择和权威历史替换。浏览器测试在独立 QA 项目运行真实模型工具调用，检查磁盘内容并实际操作恢复与 Git 按钮。
