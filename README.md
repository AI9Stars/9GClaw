## 关于九格智能体平台

**九格智能体平台**由 **AI9Stars** 开发，以 **WorkSpace（工作舱）** 为核心，面向日常办公、内容创作、研究分析与项目协作。它将文件、记忆和技能按项目组织起来，让智能体在持续工作的过程中积累知识、调用工具，并将成果保存为文件。

平台围绕白盒记忆、智能路由和后台常驻执行构建，支持多模型接入及工具扩展，适用于单次问答、多任务并行和长周期项目。

## 核心能力

- **工作舱隔离**：每个项目拥有独立的文件、记忆与技能，多项目并行时保持清晰的工作边界。
- **可追溯的白盒记忆**：查看、编辑和管理智能体记住的内容，支持空闲时自动整理记忆与回滚。
- **智能路由**：根据任务复杂度匹配模型，协调主智能体与子智能体，兼顾任务效果与使用成本。
- **后台常驻执行**：支持定时任务和持续监控，在后台推进工作，输出本地文件与摘要汇报。
- **Skills 与 MCP 扩展**：通过技能和工具接入外部服务与数据源，扩展智能体的工作能力。
- **任务成本统计**：按任务查看 Token 用量与费用，了解不同项目的资源消耗。
